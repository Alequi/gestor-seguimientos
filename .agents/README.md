# Desarrollo agéntico

Esta carpeta contiene documentación operativa para coordinar el desarrollo del proyecto.

Estructura prevista:

- `plans/`: planes de implementación aprobados.
- `decisions/`: decisiones que complementan la PRD y los requisitos funcionales.
- `handoffs/`: traspasos temporales de contexto entre agentes.

Las instrucciones generales del repositorio están en `../AGENTS.md`.

No deben almacenarse aquí secretos, datos personales, archivos CSV reales ni respuestas de Shopify.
